# 画像ビューワ

## 1. 概要

本ソフトウェアは、フォルダ内の画像を一覧表示し、ズーム・パン・矩形指定・画素値確認・
プロファイル／ヒストグラム表示を行う **Tkinter + OpenCV ベースの画像ビューワ**である。

外観検査アルゴリズムの評価・画像確認・ROI指定による解析用途を主目的とし、
画像処理関数を動的に差し替えてリアルタイムに表示結果を確認できる。

---

## 2. 動作環境

- Python 3.x
- Tkinter
- OpenCV
- NumPy
- Pillow
- Matplotlib

---

## 3. システム構成

### 3.1 モジュール構成

| モジュール名 | 概要 |
|---|---|
| `main.py` | アプリケーションのエントリポイント、GUI構築、画像管理 |
| `canvas.py` | 画像表示Canvas、ズーム・パン・矩形操作、Canvas同期 |
| `image_info.py` | マウス位置の画素情報・矩形情報管理 |
| `image_proc.py` | 外部画像処理フック（差し替え用） |
| `opencv_func.py` | OpenCV画像処理ユーティリティ |
| `ini_file.py` | 設定ファイル（INI）管理 |
| `sub_window.py` | プロファイル・ヒストグラム表示ウィンドウ |

---

## 4. GUI構成

### 4.1 画面レイアウト

- 左ペイン  
  - ファイル操作
  - 画像情報表示（座標・画素値など）
  - 操作ボタン

- 右ペイン  
  - 画像表示Canvas（行×列のグリッド表示）

---

## 5. 画像表示仕様

### 5.1 表示方式

- 指定ディレクトリ以下を再帰的に探索して画像を取得
- 行×列（最大 4×4）で同時表示
- 各画像は独立した Canvas に表示

### 5.2 スケーリング

- 初期表示時はウィンドウサイズにフィット
- ズーム倍率範囲
  - 最小：1.0
  - 最大：5.0

---

## 6. マウス操作仕様

### 6.1 操作モード

右クリックメニューから切替可能

| モード | 操作内容 |
|---|---|
| Pan | 左ドラッグで画像移動 |
| Rect | 左ドラッグで矩形（ROI）指定 |

### 6.2 ホイール操作

- マウス位置を中心にズームイン／アウト
- 拡大時も表示中心のずれを防止

---

## 7. Canvas同期機能

- 複数Canvas間で以下を同期
  - ズーム倍率
  - 表示中心座標
  - 操作モード（Pan / Rect）
- ROI（矩形指定）も全Canvasに同期描画

---

## 8. 画像情報表示

### 8.1 マウス追従表示項目

- 画像座標（X, Y）
- BGR値
- HSV値
- 矩形指定時の幅・高さ（pixel）

---

## 9. 右クリックメニュー仕様

| 項目 | 内容 |
|---|---|
| pan / rect | 操作モード切替 |
| profile (hor) | 水平プロファイル表示 |
| profile (ver) | 垂直プロファイル表示 |
| histogram (rgb) | ROI内RGBヒストグラム表示 |
| save image | 表示中画像を保存 |
| show info | ファイルパス・画像サイズ表示 |
| reset view | ズーム・位置・ROIを初期化 |

---

## 10. プロファイル・ヒストグラム表示

### 10.1 プロファイル

- 指定座標を中心とした輝度プロファイル
- 水平・垂直方向対応
- Matplotlib 別ウィンドウ表示

### 10.2 ヒストグラム

- ROI内画素値分布（RGB）
- 正規化表示
- Matplotlib 別ウィンドウ表示

---

## 11. 画像処理フック機構

### 11.1 概要

- `image_proc.py` の `img_proc(img)` を動的に読み込み
- GUIから有効／無効を切替可能

### 11.2 想定用途

- 輝度補正
- フィルタ処理
- 検査アルゴリズムの試験実装
- 学習前処理の検証

---

## 12. 画像ナビゲーション

### 12.1 操作

- 次画像／前画像切替
- ファイル番号ジャンプ
- ファイル名ワイルドカードフィルタ

### 12.2 キーボードショートカット

| キー | 動作 |
|---|---|
| ↑ | 前の画像群 |
| ↓ | 次の画像群 |

---

## 13. 設定ファイル（INI）

### 13.1 設定例

```ini
[GUI]
win_size = 1000x700
col_num = 2
row_num = 2
zoom = 1.0
um/pixel = 1.0
topmost = yes
img_file_key = *.png

## 13.2 設定項目一覧

| 項目名 | 内容 | 備考 |
|---|---|---|
| `win_size` | 初期ウィンドウサイズ | `幅x高さ` 形式（例：`1000x700`） |
| `col_num` | 画像表示の列数 | 最大 4 |
| `row_num` | 画像表示の行数 | 最大 4 |
| `zoom` | 初期ズーム倍率 | Canvas初期表示倍率 |
| `um/pixel` | 1画素あたりの実寸スケール | 現状は表示のみ（将来拡張用） |
| `topmost` | 常に最前面表示するか | `yes / no` |
| `img_file_key` | 初期画像検索キー | ワイルドカード指定可（例：`*.png`） |

## 14. 想定用途

本画像ビューワは、以下のような用途での使用を想定している。

- 外観検査アルゴリズム開発時の画像確認
- 欠陥部位の ROI 指定による寸法・輝度・画素値の確認
- 学習用データ（OK / NG）の目視評価
- 推論結果や前処理結果の比較確認
- 少量多品種・試作ラインにおける検査画像の解析支援
- 研究・開発部門における画像処理パラメータ検討・デバッグ
